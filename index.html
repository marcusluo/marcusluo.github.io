Analogue LED Clock

A charlieplexed 26-LED clock built on Arduino Uno R4 WiFi — accurate, handcrafted, and unexpectedly fun.

Arduino C++Charlieplexing3D PrintingHardware

Overview

Built with William Conn and Marcus Luo as part of a Systems Engineering class, this project is a fully functional analogue clock using 26 charlieplexed LEDs arranged in a circular face — no RTC module required. The time is tracked purely in software using millis(), and the whole thing runs on an Arduino Uno R4 WiFi with just 6 pins controlling all the LEDs.

How It Works

⚡ Charlieplexing

6 Arduino pins control 26 LEDs using Charlieplexing — a technique that exploits tri-state logic (HIGH, LOW, INPUT) to drive far more LEDs than pins available.

⏱ Software Clock

No RTC required. Time is tracked using Arduino's millis() function and a base time set via Serial commands (new HH:MM:SS).

🕐 Clock Layout

12 outer LEDs show minutes in 5-minute increments. 12 inner LEDs show the hour. 2 centre LEDs indicate AM/PM.

🎰 Hidden Modes

Secret serial commands unlock a light show, a kaboom spin animation, a top-of-hour blink, and even a roulette gambling mode with smooth slowdown.

Serial Commands

new HH:MM:SSSet the current time
clockReturn to normal clock display
lightsTrigger light show mode
kaboomSpin animation (hour & minute orbit)
gamblingEnter roulette mode
spinSpin the roulette wheel
testTrigger hour blink diagnostic

Challenges

  • Counter-clockwise wiring — Will wired the clock face anti-clockwise, meaning LED 3 showed 55 min instead of 5. Fixed by correcting connections and updating the code mapping.
  • LED flicker — Too many simultaneous LEDs caused violent flashing due to PWM pin limitations. Solved with careful multiplexing timing.
  • Charlieplex complexity — Understanding and physically wiring a 26-LED charliplex matrix was the biggest challenge of the project.
  • Cable chaos — The back of the clock required pliers to reach pins between the mass of wiring. A housing cover is planned for future revisions.

Future Improvements

  • Thicker, more rigid 3D-printed casing with higher infill
  • Rear wiring housing to hide all cabling
  • Passive buzzer for hourly chimes and alarms
  • LED diffuser covers for a cleaner, more polished look

const int CH[6] = {3,5,6,9,10,11};

void lightLED(int index) {
  int an = LED_PINS[index][0];
  int ca = LED_PINS[index][1];
  allPinsOff();
  pinMode(CH[an], OUTPUT);
  pinMode(CH[ca], OUTPUT);
  digitalWrite(CH[an], HIGH);
  digitalWrite(CH[ca], LOW);
}
